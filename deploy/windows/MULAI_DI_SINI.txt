RMS COLLECTOR OPC UA ONLY

1. Baca PANDUAN_IGNITION_OPCUA.md.
2. Sesuaikan endpoint di config\collector.opcua.conf.
3. Sesuaikan IP/controller di config\robots.opcua.conf.
4. Jalankan TEST_OPCUA.cmd untuk simulasi.
5. Hubungkan Ignition dan percayai certificate kedua arah.
6. Hentikan simulasi, lalu jalankan START_OPCUA.cmd untuk robot aktual.
7. Aktifkan koneksi database dan pencatatan data di Ignition.

CHECK_SDK.cmd hanya memeriksa DLL vendor tanpa menghubungkan robot.
Paket Windows membutuhkan .NET Runtime 10 x64 atau SDK 10 x64.
